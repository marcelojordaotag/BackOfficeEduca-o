# Centro Educacional Backoffice

Ambiente educacional com mini aulas sobre os processos do Backoffice (React + Vite).

```bash
npm install
npm run dev
```

- Conteúdo das aulas: `src/data/aulas.js` (cada aula tem objetivo, por que fazemos, passo a passo, dicas e um teste rápido).
- Telas: início (apresentação), lista de aulas por módulo e página de aula.
- O progresso do aluno fica salvo no navegador (localStorage).
